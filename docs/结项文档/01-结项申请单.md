## 2. 项目背景与目标

本地开发目录长期积累后，常出现项目分散、体积不清、依赖缓存和构建产物占用大量空间、旧项目源码是否已推送难以判断等问题。人工清理存在误删源码和 Git 历史的风险。

本项目目标：

1. 只读盘点本地项目，输出体积、时间和 Git 状态。
2. 对可恢复项目记录远程 URL 与提交 SHA，避免重复打包。
3. 对不可恢复项目生成可校验的 `tar.gz` 归档。
4. 按 manifest 恢复 Git 项目或归档项目，默认恢复到备份时的原始位置，也可用 `--dest` 恢复到新目录；归档默认校验 SHA-256，不覆盖已有目录。
5. 按白名单清理构建产物，默认不删除，删除前必须显式确认。
6. 始终保护项目根目录、`.git` 目录和符号链接目标。
