## 2. 项目概况

`proj_janitor` 面向长期积累大量本地代码目录的开发者，提供三个核心能力：

1. `scan`：发现项目目录，统计体积、最后修改时间、项目标记、Git 分支与工作区状态。
2. `backup`：对可恢复项目采用“Git 远程 URL + 提交 SHA”的轻量记录；对不可恢复项目回退为 `tar.gz` 归档，并写入清单与 SHA-256。
3. `clean`：按白名单规则识别构建产物与依赖缓存，默认只展示计划，显式确认后才删除。

工具仅依赖 Python 标准库和本机 Git 命令，通过 `projjan` 入口或 `python3 -m proj_janitor` 运行，不包含服务端、数据库、Web UI 或网络监听。
