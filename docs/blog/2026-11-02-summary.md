# proj-janitor 项目进展（2026-11-02）

## 版本发布

- Rust `proj-janitor 0.2.6` 已发布至 crates.io，tag 为 [`v0.2.6`](https://github.com/TangCan/proj-janitor/releases/tag/v0.2.6)，GitHub Release 已创建。
- 功能代码提交：`c58c67c4fddd1b08f45fb383554b00ec32413e7c`；Python 包仍为 `0.1.0`。
- 版本包含 `--exclude-git-metadata`、干净 GitHub 项目的子模块轻量备份/恢复、默认 GitHub LFS endpoint 的轻量备份/恢复，以及近期归档和 manifest 身份检查改进。
- `cargo publish --locked` 上传成功；随后从 crates.io 安装 `0.2.6`，`projjan --version` 输出 `projjan 0.2.6`。
- 发布后 main 已进入 Rust `0.2.7` 开发版；修复 Rust `backup --help` 在设置 `BACKUP_DEST` 时回显实际路径的问题，并新增 CLI 回归，避免帮助输出泄露本机目录。该修复尚未发布。
- 随后修复 Python 备份失败清理边界：`os.fdopen` 失败或归档名被并发抢占时，仅清理身份匹配的本次输出；身份查询 `fstat` 失败会关闭描述符，POSIX 回归验证替换路径文件不会被删除。当前提交 `dd24f71`。
