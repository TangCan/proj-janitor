## 更新内容

- `backup --encrypt-passphrase-file` / `[backup].encrypt_passphrase_file` / `--no-encrypt`：用 openssl AES-256-CBC+PBKDF2 加密 archive/bundle，输出 `.enc`，manifest 记录 `encryption`。
- `restore --decrypt-passphrase-file` / `[restore].decrypt_passphrase_file`：解密后恢复。
- 需要 PATH 中有 `openssl`；默认不加密。
