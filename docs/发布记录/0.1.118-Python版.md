## 更新内容

- **缺陷修复**：同一秒内创建的多个快照，文件名后缀在保留清理后会被回收复用（如 `-2` 被删后又用于新快照）。retention 原先按 `(stamp, suffix)`/路径排序，会把**最新备份误判为最旧并删除**；用 `--keep` 的快速连续备份可复现（Rust 在第 7 轮即丢失最新快照）。
- 修复：retention 改为按 manifest 内 `created_at`（含亚秒）排序，名称仅作兜底；Python/Rust 双端一致。
- 新增 `scripts/soak.sh`：参数化有界 soak（backup + verify + restore + `--keep`），检查恢复内容、保留上限与临时目录残留。

## 回归
