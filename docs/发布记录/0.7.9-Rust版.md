## 更新内容

- `backup` 新增 `--progress` / `--no-progress`，以及配置默认值 `[backup].progress`。
- 开启时 archive 打包向 stderr 输出文件计数进度；配合 `--dry-run` 时按排除规则估算将打包的文件数与字节数（缓解 R-08 可观测性）。
- 默认行为不变：不输出进度。
