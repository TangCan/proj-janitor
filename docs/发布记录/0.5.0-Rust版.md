## 更新内容

- `verify` 新增 `--check-remote`：对 Git-only 记录执行一次 `git ls-remote`（30 秒超时、`GIT_TERMINAL_PROMPT=0`、经参数列表调用、不下载对象），只读取引用列表判定远端可达性，状态为 `remote-verified`/`remote-moved`/`remote-unreachable`/`remote-skipped`；`--json` 增加脱敏的 `remote` 对象（`url`、`branch`、`reason`、排序去重后的 `refs`）。默认仍离线，不带该选项不会触发任何 Git 子进程。
- `restore` 新增 `--check-remote`：复用同一远端探测，在 SHA-256 校验与恢复位置确认之后、创建任何目标目录之前对每个 Git-only 计划预检；任一远端不可达时整批不开始并返回 `1`，报 `cannot restore <项目>: remote <脱敏URL> is unreachable`。`archive`/`git_bundle` 计划忽略该选项；含凭据/查询/片段参数的 URL 不会传给 Git、保持离线。
- Python 打包就绪：推荐 `pipx` 从 Git 源码安装、Python 源码分发 CI、`publish-python.yml` 安全干运行（默认不发布，需 Trusted Publisher 配置）。
- 健壮性修复：拒绝非 UTF-8 备份路径、Unicode 保留名与 DEL 文件名校验在 Python/Rust 间对齐、`prune` 严格 schema 校验（整数保留版本、后缀边界、项目名校验）、格式异常的保留清单跨实现覆盖。
- 依赖更新：`globset 0.4.21`、`signal-hook 0.4.6`、`gh-action-pypi-publish 1.14.3`。
- manifest schema v2 不变；Rust 与 Python 行为保持对齐。
