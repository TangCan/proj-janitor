## 更新内容

- Windows 归档恢复现在根据链接目标类型创建文件符号链接或目录符号链接。
- 归档内项目路径与链接目标仍需通过越界校验；符号链接在普通文件与目录完成解压后创建。
- Windows 运行账户必须拥有符号链接创建权限；若权限不足，恢复会报错并清理临时解压目录。

## 发布验证

- `cargo fmt --check`、`cargo clippy --all-targets --locked -- -D warnings`、Rust 12 项测试通过。
- GitHub Actions 对 Linux、macOS 15、Windows 2025 的 Rust CI 全部通过；Windows 日志确认文件与目录符号链接往返测试实际执行。
- `cargo package --locked` 与 `cargo publish --dry-run --locked` 成功。
- `cargo publish --locked` 发布成功；从 crates.io 安装 `0.2.1` 并运行 `projjan --version`，输出 `projjan 0.2.1`。

Windows 符号链接恢复使用 Rust 标准库 `symlink_file`/`symlink_dir`；这些操作需要系统授予符号链接创建权限。参见 [Rust Windows symlink API](https://doc.rust-lang.org/std/os/windows/fs/fn.symlink_file.html)。
