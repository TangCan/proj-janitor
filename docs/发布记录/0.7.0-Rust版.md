## 更新内容

- 子模块远端预检（CR-094）：Git-only（`git` 策略）记录的 manifest 新增可选字段 `submodules`（`[{path, url, commit}]`，为备份时 `.gitmodules` 中的每个子模块记录其路径、远程 URL 与父树中固定的 gitlink 提交，经 `git ls-tree <commit> -- <path>` 解析）。`verify`/`restore --check-remote` 对每个子模块的 URL+固定提交复用同一 `git ls-remote` 预检（单条最长 30 秒、`GIT_TERMINAL_PROMPT=0`、参数列表调用、不下载对象、凭据/query/fragment 脱敏）；任一子模块远端 `remote-unreachable` 时 `verify` 置项目级 `status` 为 `remote-unreachable`，`restore` 在创建任何目标目录之前整批不开始并报 `cannot restore <项目>: submodule <path> remote <脱敏URL> is unreachable (<原因>)`。
- LFS 指针 OID 记录（CR-094）：Git-only 记录的 manifest 新增可选字段 `lfs_objects`（`[<64 位十六进制 OID>]`，为备份时 `git lfs ls-files --long` 记录到的 Git LFS 指针对象 OID，仅记录、不探测对象可用性）。LFS 对象*可用性*探测留待后续（git-lfs 无“不下载对象”的 OID 检查命令，需 LFS batch API HTTP）。
- manifest schema v2 不变（`submodules` 与 `lfs_objects` 为可选字段，向后兼容，无 schema_version 变更）；`archive`/`git_bundle` 策略不受影响；Rust 与 Python 行为保持对齐。
