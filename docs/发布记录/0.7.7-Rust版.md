## 更新内容

- archive 策略新增 `--exclude-secrets` / `--no-exclude-secrets`，以及配置默认值 `[backup].exclude_secrets`。
- 开启时打包跳过常见敏感路径，并向 stderr 输出 `note: … excluding secret paths`。
- 与 `--fail-on-secrets` 同时开启时优先排除（不拒绝备份）。默认行为不变。
