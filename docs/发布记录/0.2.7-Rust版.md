## Rust crate 更新

- `backup --help` 不再显示 `BACKUP_DEST` 当前值，只显示环境变量名，避免帮助文本暴露本机备份路径。
- Manifest schema 仍为 v2；默认备份/恢复策略不变。

Python 源码也有独立的备份失败清理改进，但不打入 Rust crate：创建文件后若句柄包装或身份查询失败，只清理身份已确认的文件；归档名冲突时保留并发创建的文件。
