## 更新内容

- CR-193：`COM`/`LPT` 保留名判定改为「NFKC 归一化后，后缀为单个 Unicode 十进制数字（1–9）」。
  - 使用 `unicode-general-category` 判定 `GeneralCategory::DecimalNumber`，与 Python `unicodedata.decimal` 对齐。
  - 覆盖既有 ASCII、上标、全角、带圈、阿拉伯/波斯数字，并统一覆盖其他文字的十进制数字（如天城文 `१`、泰文 `๑`、孟加拉文 `১`、数学数字 `𝟙`）。
  - `COM0` / `LPT0`、`COM10`、CJK 数字 `COM四`、罗马数字 `COMⅨ`、分数 `COM½`、带圈十 `COM⑩` 仍允许。
- 新增依赖 `unicode-general-category` 1.1.0（无传递依赖）。
- crate 版本 `0.7.90`。
