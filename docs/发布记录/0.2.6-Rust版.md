## 候选更新内容

- 增加 `--exclude-git-metadata` 备份选项，在 archive 策略下可排除项目中的 `.git`，用于不需本地 Git 历史的工作树快照。
- 默认备份行为不变；archive 策略启用该选项时，清单字段 `exclude_git_metadata` 为 `true`；它记录选项状态，即使源项目没有 `.git`。
- Python/Rust 两种实现的选项行为和 manifest 保持一致。

此候选不会修改已存在的备份。排除 `.git` 的恢复副本不含 Git 历史、分支、tag 或 remote；应只在这些信息可从其他来源恢复时使用。
