## 更新内容

- `.proj-janitor.toml` 支持 `[verify].check_remote` / `[restore].check_remote`，可将远端/子模块/LFS 预检设为默认开启。
- `verify` / `restore` 新增 `--no-check-remote` 覆盖配置；二者亦支持 `--config`。
- 默认 CLI 行为仍为离线；显式 flag 优先于配置。
- 文档同步 R-02 缓解路径与验收闭环状态。
