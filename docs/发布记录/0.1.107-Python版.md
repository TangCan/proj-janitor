## 更新内容

- CR-239：`verify` 新增 `--decrypt-passphrase-file`（及 `[verify].decrypt_passphrase_file` 配置）。
  - 提供 passphrase 时：先校验密文 SHA-256，再解密到临时文件并用与 `restore` 相同的成员校验规则（路径、保留名、控制字符、符号链接、硬链接、重复/大小写碰撞）检查内部归档，随后清理临时文件。
  - 未提供 passphrase 时：保持原有行为，仅校验密文，并在 stderr 提示 `ciphertext only`。
- 加密备份的 `verify` 因此可以提前发现 passphrase 错误或内部归档损坏，不必等到 restore。
- 解密校验复用 `restore` 的共享成员校验函数，避免两套规则漂移。
