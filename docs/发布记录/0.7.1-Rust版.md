## 更新内容

- 修复 `git_bundle` 恢复在分支名与 `git init` 默认分支相同（常见为 `master`）时失败：现代 Git 拒绝 `fetch` 进当前检出分支（`refusing to fetch into branch '…' checked out at …`）。恢复时先将 HEAD 指到未出生的 `refs/heads/projjan-restore-temp`，再拉取 bundle 中的分支与标签（CR-095）。
- 修复从非 git 仓库目录（例如 `$HOME`）运行 `restore` 时 `git bundle verify` 失败（`need a repository to verify a bundle` → 工具报 `invalid Git bundle`）：改为在已初始化的临时恢复仓库内执行 `git -C repo bundle verify`（CR-095）。
- 既有 `0.7.0` 生成的 `git_bundle` 备份无需重做；使用 `0.7.1+` 重新 `restore` 即可。Rust 与 Python 行为保持对齐；manifest schema v2 不变。
