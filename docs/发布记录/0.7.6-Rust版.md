## 更新内容

- archive 策略新增 `--fail-on-secrets` / `--no-fail-on-secrets`，以及配置默认值 `[backup].fail_on_secrets`。
- 开启时若启发式检测到常见敏感路径，拒绝该项目备份：stderr 报错、不写归档/manifest、非零退出。
- 默认行为不变：仍仅告警并继续备份（CR-099）；归档仍不加密。
