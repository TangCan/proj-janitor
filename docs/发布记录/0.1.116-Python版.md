## 更新内容

- **缺陷修复**：Python 恢复加密增量快照时，delta 归档未解密，直接按 tar 打开密文导致失败（`method gz: Read`）。现在每个 delta 在解密后提取，并先校验密文 SHA-256。
- 行为与 Rust 端一致（Rust 原本已支持；本轮补测试固化）。
- 未提供 passphrase 时与单归档一致：报 `encrypted archive requires --decrypt-passphrase-file`。

## 回归

- Python `EncryptedIncrementalRestoreTests`：加密 base + 加密 delta 恢复后内容正确、删除项移除、新增项存在；缺 passphrase 报错。
- Rust `restore_reconstructs_encrypted_incremental_chain` 覆盖同一场景（restore.rs 相关分支由未覆盖转为覆盖）。
- 全量 Python 455 项、Rust 110 单元 + 108 CLI 通过。
