## 更新内容

- GitHub Git-only 不适用时，干净、非浅克隆、无 stash、无子模块/LFS 的仓库可生成 `.bundle`，保存本地分支、tag 及可达提交历史。
- manifest 使用 `strategy: "git_bundle"`，复用 `archive` 字段保存 bundle 路径，并记录 SHA-256、分支和提交；Python、Rust 可以互相校验和恢复。
- `--always-archive`、`--include-artifacts`、`--exclude-git-metadata` 继续强制走归档；敏感远程/Git 配置仍阻止自动备份。
- bundle 不包含 Git 配置、reflog、stash、悬空对象、子模块对象或 LFS 对象；历史中已提交的敏感内容会被保留。
