## 更新内容

- `backup` 新增 `--fail-on-insecure-dest` / `--no-fail-on-insecure-dest`，以及配置默认值 `[backup].fail_on_insecure_dest`。
- 开启时，若既有备份目标目录在 Unix 上含 group/other 权限位则拒绝备份（缓解 R-05）。
- Windows 上该检查为 no-op；默认行为不变。

## 发布前验证

- Python 250 项（249 通过、1 项 Windows 专属跳过）；Rust 83 单元 + 40 CLI。
- `cargo fmt --check`、Clippy `-D warnings` 通过。
- 回归：`backup_fail_on_insecure_dest_refuses_open_directory`、`insecure_dir_mode_detects_group_or_other_bits`。
