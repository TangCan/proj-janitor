## 更新内容

- CR-218：新增 `restore --check-space`。恢复 archive 前按归档声明的解压后总大小比较目标盘可用空间，不足即拒绝，避免超大归档写满磁盘。
- 仅检查普通 archive；加密归档与增量归档跳过（无法在不解密/展开链的情况下可靠估算）。
- 对超大或稀疏成员提前停止扫描，避免恶意归档让预检本身消耗大量时间。
- 统计按 `dest` 父目录（或原始目标父目录）所在文件系统可用空间判断。
