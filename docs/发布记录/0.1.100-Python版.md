## 更新内容

- CR-223：`restore --check-space` 现在把同一目标父目录下的多个 archive 计划按**合计大小**与可用空间比较，避免逐个检查都通过、批量恢复却中途写满。
- 错误信息包含目录、项目列表、合计需求与可用字节数。
- 扫描某个归档时以剩余预算为上限，仍保留超大/稀疏成员提前停止。
- 与 Rust 端行为一致。
