## 发布范围

本版本为 Python CLI 首发，与当前 `main` 功能对齐，包含：

- 扫描、备份（`git` / `git_bundle` / `archive`）、恢复、校验、保留清理与白名单清理
- `.proj-janitor.toml` 配置文件（CR-090）、`backup --keep` 自动保留（CR-091）、`[backup].exclude`（CR-092）、`backup --incremental`（CR-093）
- `verify`/`restore --check-remote` 远端预检及子模块扩展与 LFS OID 记录（CR-088/089/094）
- `git_bundle` 恢复修复：默认分支 fetch 冲突与非 git cwd 下 verify（CR-095）
