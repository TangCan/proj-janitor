- Workflow filename: `publish-python.yml`

pending publisher 允许在项目尚不存在时配置，但不会预留项目名；首次可信发布成功后才会创建项目并完成绑定。配置要求见 [PyPI 创建 Trusted Publisher 文档](https://docs.pypi.org/trusted-publishers/creating-a-project-through-oidc/)。

## 发布步骤

1. 在 PyPI 发布设置中配置本记录列出的 Trusted Publisher。项目当前仍未在 PyPI 创建；pending publisher 不会预留项目名。
2. 从 GitHub Actions 的 `main` 手动运行 `Publish Python package`，输入 tag `python-v0.1.0` 并将 `publish` 设为 `true`。
3. 工作流会再次确认 tag 可达 main 且版本匹配，再构建 sdist/wheel、运行 `twine check` 和隔离安装，最后在仅有 `id-token: write` 权限的独立 job 中上传。
4. 上传成功后更新本记录和结项文档，验证 PyPI 项目页及 `pip install proj-janitor==0.1.0`。
