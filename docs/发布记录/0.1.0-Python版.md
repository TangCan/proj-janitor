## 一次性 PyPI 配置

在 PyPI 的发布设置中创建 pending Trusted Publisher：

- PyPI project name: `proj-janitor`
- GitHub owner: `TangCan`
- Repository: `proj-janitor`
- Workflow filename: `publish-python.yml`
- GitHub environment: `pypi`

pending publisher 允许在项目尚不存在时配置，但不会预留项目名；首次可信发布成功后才会创建项目并完成绑定。配置要求见 [PyPI 创建 Trusted Publisher 文档](https://docs.pypi.org/trusted-publishers/creating-a-project-through-oidc/)。

## 发布步骤

1. 在 main 上完成 Python 发布版 README 和文档校对；发布 tag 的 `pyproject.toml` 版本必须仍与 tag 一致。
2. 创建并推送 `python-v0.1.0` tag，指向 main 中同版本源码。
3. 在 GitHub Actions 中从 `main` 手动运行 `Publish Python package`，输入 tag `python-v0.1.0`。
4. 工作流先确认 tag 可达 main 且版本匹配，再构建 sdist/wheel、隔离安装冒烟，最后在仅有 `id-token: write` 权限的独立 job 中上传。
5. 上传成功后更新本记录和结项文档，验证 PyPI 项目页及 `pip install proj-janitor==0.1.0`。

工作流不会自动因 tag push 发布；PyPI 配置完成前不会上传发行包。
