## 更新内容

- Git 恢复改用临时仓库和 fetch，避免认证 URL 写入 `.git/config` 或 `FETCH_HEAD`；Git 支持配置环境传递时，敏感 URL 不进入进程参数。
- Git 恢复子进程增加超时和进程树清理；失败信息会列出批量恢复中已完成的项目。
- 归档路径校验增加 Windows 保留名称、备用数据流、重复成员和 Unicode 规范化冲突检查；Python/Rust 备份与恢复行为对齐。
- Windows 路径展开支持 `USERPROFILE`、`~/` 和 `~\\`；空备份目标会被拒绝。
- 备份失败清理、Rust MSRV/包构建和 Python 最低支持版本 wheel 安装检查得到加强。
