## 更新内容

- 修复恢复时将 GNU sparse（`EntryType::GNUSparse`，常见于带洞 ELF）误判为 special file 而失败。
- 备份写入改为 `Builder::sparse(false)`，与 Python `tarfile` 一致，避免新归档再产出 sparse 头。
- 仍接受既有 sparse/contiguous 成员以便恢复旧备份（如 TxPlane `kernel.elf`）。

## 发布前验证

- Python 267 项（266 通过、1 项 Windows 专属跳过）；Rust 91 单元 + 49 CLI。
- `cargo fmt --check`、Clippy `-D warnings` 通过；对含 GNU sparse 的 `TxPlane-demo` 归档实测恢复成功。
