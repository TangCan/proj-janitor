## 更新内容

- CR-097：与 Rust 对齐的 LFS 对象可用性探测——备份记录 `lfs_objects:[{oid,size}]`；`verify`/`restore --check-remote` 检查本地 LFS 对象库或调用 HTTPS LFS batch API（不下载对象）。
- 缺失或不可达时 verify 状态 `lfs-unavailable`；restore 在创建目标前整批中止。
- `__version__` 与 `pyproject.toml` 均为 `0.1.3`。
