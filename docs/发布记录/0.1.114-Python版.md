- CR-247：`backup --json` 在真实备份成功时输出 JSON：
  - `manifests`：manifest 路径列表
  - `records`：project/source/strategy/archive/archive_bytes/source_bytes/sha256/commit/remote_url/branch/fallback_reason/encryption
