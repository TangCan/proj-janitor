## 更新内容

- CR-245：`verify` 对增量快照逐级读取 base manifest，并校验链上每个归档的 SHA-256；base 缺失、名字非法、循环、过深、跨非 archive 快照或哈希不匹配都会使 verify 失败。
- 取代 0.1.111 的 "base chain 未检查" 警告：现在整条链都会被校验。
- Python/Rust 双端一致。
