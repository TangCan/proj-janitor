## 更新内容

- 新增 `prune BACKUP_ROOT --keep N`，按项目目录保留最新 N 份清单；默认只预览，显式 `--apply` 才删除。
- `--apply` 在终端列出待删文件并确认；非交互或 JSON apply 需要 `--yes`。
- 只删除旧 manifest 及其明确引用、位于同一项目目录且没有被保留清单引用的 archive/bundle；孤立文件和旧版时间戳运行目录不处理。
- Python/Rust 使用同一规划行为和 JSON 结构；跨实现保留测试覆盖。
