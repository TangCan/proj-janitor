## 更新内容

- CR-239：`verify` 新增 `--decrypt-passphrase-file`（及 `[verify].decrypt_passphrase_file`）。
- 提供 passphrase 时：密文校验后解密，并用 `validate_archive_for_verify` 校验内部成员路径、符号链接目标、硬链接、重复/大小写碰撞；随后清理临时目录。
- 未提供时保持密文校验并提示 ciphertext-only。
- 与 Python 端行为一致。
