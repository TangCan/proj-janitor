## 更新内容

- **健壮性修复**：增量恢复此前先把基线发布到目标，再就地把 delta 写入目标；若中途失败（恶意/损坏 delta 等），目标会残留"基线 + 部分 delta"的半成品，且 `--rollback-on-error` 不会清理（它只回滚已成功项目）。
- 现在整条链在目标父目录下的暂存树中重建（基线 → 删除项 → 逐 delta），**全部成功后一次发布**；失败时目标不存在、暂存目录清理，与单归档恢复的原子性一致。
- 加密基线/加密 delta 的既有解密逻辑保持不变。
- Python/Rust 双端一致。
