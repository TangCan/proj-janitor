## 更新内容

- 项目体积扫描遇到遍历期间已消失的单个文件时继续扫描；权限和其他 I/O 错误仍报告。
- 目录专属归档可由 Rust 正确恢复，并加入 Python↔Rust 双向兼容回归测试。
- Windows 的制品匹配大小写语义与 Python 对齐；保留设备名、非法路径组件和大小写冲突在恢复前拒绝。
- Unix 新建备份根目录/项目目录使用 `0700`，归档与 manifest 使用 `0600`；不改变已有目录权限。Windows 继续继承父目录 ACL。
- Rust artifact glob matcher 只编译一次并在扫描过程中复用。
