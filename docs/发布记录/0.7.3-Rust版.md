## 更新内容

- 备份时 `lfs_objects` 改为记录 `{oid,size}`（`git lfs ls-files --long` + pointer blob）；旧清单中的裸 OID 字符串仍可读。
- `verify` / `restore --check-remote` 探测 LFS 对象可用性且**不下载**对象：本地/`file://`/`url.*.insteadOf` 检查 `lfs/objects`；HTTPS 调用 LFS batch API（`ureq`）。
- 缺失或不可达时 verify 置 `lfs-unavailable` 并退出 `1`；restore 在创建任何目标目录前整批不开始。
- 依赖新增 `ureq`（TLS）仅用于 HTTPS LFS batch 预检。
- manifest schema v2 不变（可选字段形状扩展，向后兼容）。
