## 更新内容

- CR-243：`verify` 结果对人类输出与 JSON 增加内部校验状态：
  - 加密归档解密校验成功 → `(decrypted archive checked)`
  - Git bundle 头校验成功 → `(bundle header checked)`
  - `--json` 对 archive/git_bundle 记录增加 `inner_checked` 布尔字段
- 未做内部校验时（加密无 passphrase）不标注，仍保留 ciphertext-only 警告。
- Python/Rust 输出与 JSON 结构一致（跨实现套件校验）。
