## 更新内容

- CR-145：`backup`/`restore` 在 Unix 上发现 group/other 可访问的备份目标或恢复路径、且未启用 `--fail-on-insecure-dest` 时，向 stderr 提示 `warning: ... insecure permissions ...; pass --fail-on-insecure-dest to refuse`，提高 R-05 可见性（默认仍不硬失败）。
- `__version__` 与 `pyproject.toml` 均为 `0.1.46`。
