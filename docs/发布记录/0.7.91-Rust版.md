## 更新内容

- CR-194：`safe_windows_component` 先对组件名做 NFKC 归一化，再提取 stem 与保留名/设备名规则比对。
  - 新增拒绝：全角 `ＣＯＮ`、全角 `ｐｒｎ`、数学粗体 `𝐂𝐎𝐍`、双线体 `ℂ𝕆ℕ`、带圈 `ⒸⓄⓃ`、全角 `ＣＯＭ１` 等兼容形式。
  - 明确保留：西里尔 `СОН`、希腊 `ΟΝ` 等跨文字但非 NFKC 等价的名称；它们不是 Windows 保留设备名，避免误伤正常外文文件名。
