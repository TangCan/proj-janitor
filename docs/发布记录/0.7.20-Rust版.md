## 更新内容

- 修复 archive 备份在 symlink 目标超过 ustar `linkname` 100 字节上限时失败（`provided value is too long when setting link name`）。改为依赖 `Builder::append_link` 的 GNU long-link 扩展，不再预先调用会截断失败的 `Header::set_link_name`。
- 回归：`archive_round_trip_keeps_symlink_targets_longer_than_ustar_limit`（TxPlane 风格相对路径）。
