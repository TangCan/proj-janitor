- Rust CLI 增加只读 `verify` 命令：归档记录校验 SHA-256；Git 记录只校验 URL 与 commit 元数据，不联网确认远程。

- Unix `signal-hook` 更新到 `0.4.5`。
- Python/Rust 跨实现 verify JSON 行为一致；schema 仍为 v2。
