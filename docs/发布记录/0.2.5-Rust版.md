## 更新内容

- Rust CLI 增加只读 `verify`：归档记录校验 manifest 中的 SHA-256；Git 记录只校验 URL 和 commit 元数据，不联网确认远程。
- Windows Rust CLI 在 8 MiB 栈线程中运行，修复 Windows CLI 调用子进程时的栈溢出。
- Unix `signal-hook` 更新到 `0.4.5`。
- Python/Rust 对 archive 与 Git `metadata-only` verify JSON 结果一致；manifest schema 仍为 v2。
