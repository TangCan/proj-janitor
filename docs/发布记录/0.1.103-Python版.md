## 更新内容

- CR-229：归档组件名拒绝 `U+2028`（LINE SEPARATOR）与 `U+2029`（PARAGRAPH SEPARATOR）。
- 这两类是 Unicode 仅有的 Zl/Zp 字符，可在日志/终端中造成换行伪装；普通文件名不受影响。
- 与既有 C0/C1、`Cf`（保留 ZWJ/ZWNJ）规则一起构成完整的不可见/换行字符拒绝集。
- Python/Rust 双端一致。
