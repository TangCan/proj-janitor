## 更新内容

- CR-222：新增 `[restore].check_space` 配置项，默认 `false`。
- CLI 改为三态：`--check-space` / `--no-check-space`，未指定时使用配置默认值；显式 flag 覆盖配置。
- 与 `[backup].check_space` 的配置模式保持一致。
- 行为仍为：估算源为 inventory → `source_bytes` → 扫描；不足即拒绝。
