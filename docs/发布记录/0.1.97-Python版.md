## 更新内容

- CR-219：`--check-space` 优先使用 manifest `inventory` 的 `size` 汇总估算解压总量，因此**加密归档**也能预检。
- 无法估算时不再静默跳过：
  - 加密归档且无 `inventory` → `warning: --check-space skipped encrypted archive without inventory ...`
  - 增量归档 → `warning: --check-space skipped incremental archive ...`
- 直接调用预检时若目标父目录尚不存在，回退到最近的存在祖先取可用空间。
- 默认仍需显式 `--check-space`；行为与 Rust 端一致。
