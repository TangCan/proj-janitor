## 更新内容

- CR-240：`verify` 对 `git_bundle` 记录增加 bundle 魔数头校验（`# v2 git bundle` / `# v3 git bundle`），提前发现结构性损坏。
- 加密 Git bundle 与加密归档一致：提供 `--decrypt-passphrase-file` 时先校验密文、再解密并校验 bundle 头；未提供时提示 `encrypted bundle verified by ciphertext only`。
- 仅校验头部结构；bundle 内 pack 数据的完整性仍由 SHA-256 负责（`git bundle verify` 对无前置条件的完整 bundle 不校验 pack，故未引入 git 依赖）。
