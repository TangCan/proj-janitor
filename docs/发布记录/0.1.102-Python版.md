## 更新内容

- CR-228：归档组件名拒绝 Unicode 通用类别 `Cf`（Format）的不可见格式字符，**仅保留 ZWNJ（U+200C）与 ZWJ（U+200D）**。
- 覆盖软连字符、零宽空格、BOM、词连接符、双向控制、Tag 字符等；此前仅显式拒绝双向控制与 Tag 字符。
- ZWJ emoji 序列、波斯 ZWNJ、变体选择符、组合字符等合法 Unicode 仍允许。
- Python/Rust 双端一致。
