## 更新内容

- CR-246：`verify` 校验增量 base chain 时，若基线快照本身加密：
  - 提供 `--decrypt-passphrase-file` → 逐级解密并校验内部归档；
  - 未提供 → 提示该基线仅密文校验（ciphertext-only warning）。
- 可发现 base 与 delta 使用不同 passphrase 的不可恢复链（单次 restore 无法用同一 passphrase 解密）。
- Python/Rust 双端一致。
