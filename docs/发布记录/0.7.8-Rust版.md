## 更新内容

- `restore` 新增 `--require-dest` / `--no-require-dest`，以及配置默认值 `[restore].require_dest`。
- 开启时省略 `--dest` 则拒绝恢复，避免按 manifest `source` 写入任意路径（缓解 R-14）。
- 默认行为不变：仍允许原位恢复（需 `--yes` / 交互确认）。
