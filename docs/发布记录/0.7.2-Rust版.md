## 更新内容

- 恢复流程中带超时的 `git` 子进程改为捕获 stderr；失败时在原有笼统消息后附加一行脱敏详情（例如 `invalid Git bundle for ZKCA: fatal: …`），避免仅看到 `invalid Git bundle` 而无法定位（CR-096）。
- 含凭据的 `https://user:token@…` URL 在详情中统一替换为 `remote URL details redacted`。
- timed restore git 子进程设置 `GIT_PAGER=cat`，降低交互终端下 pager 干扰。
- Rust 与 Python 行为对齐；manifest schema v2 不变。

## 发布前验证
