## 更新内容

- CR-250：`backup --dry-run --json` 输出计划 JSON：
  - `dry_run: true`
  - `manifests`：将被写出的 manifest 路径（不含 blocked）
  - `plans`：每项目策略（`archive`/`git`/`git_bundle`/`blocked`）、archive 路径、reason、`refused` 标记；archive 计划带 `size_bytes`，`--progress`/`--check-space` 时附 `estimated_files`/`estimated_bytes`
- 拒绝（check-space/秘密/不安全路径）仍走 stderr 并以非零退出，但 JSON 中对应计划带 `refused: true`。
- `--json --dry-run` 组合从"拒绝"变为"输出计划"；`--json --keep` 仍互斥（退出码 1）。
- Python/Rust schema 一致；至此 `backup` 与其他主命令一样具备完整 JSON 能力。
