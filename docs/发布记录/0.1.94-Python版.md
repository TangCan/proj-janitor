## 更新内容

- CR-216：`_safe_windows_component` 拒绝 Unicode 双向控制字符（Trojan-Source 类文件名伪装）：
  - `U+061C`、`U+200E`、`U+200F`、`U+202A`–`U+202E`（LRE/RLE/PDF/LRO/RLO）、`U+2066`–`U+2069`（LRI/RLI/FSI/PDI）。
  - 带这些字符的归档成员在备份预检和恢复时都会被拒绝；普通 Unicode 文件名不受影响。
- `__version__` 与 `pyproject.toml` 均为 `0.1.94`。
