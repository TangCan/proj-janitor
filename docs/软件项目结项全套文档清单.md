# 软件项目结项全套文档清单
按**项目管理、需求设计、开发实现、测试、部署运维、交付验收、结项归档**分类，区分【必选】和【可选】，适配企业自研、外包、政府/招投标项目（招投标项目一般要求更全）。

> 说明：小项目可以合并精简，大项目、涉密/政务项目要严格分开、单独归档。

## 一、项目管理类（必选）
1. **项目立项书 / 任务书**
2. **项目章程**（部分公司有）
3. **项目开发计划（总体计划）**：范围、进度、人员、里程碑、风险
4. **变更记录 / 变更申请单（CR）**：需求变更、方案变更、评审记录
5. **会议纪要**：周会、评审会、问题讨论会
6. **风险台账 & 问题跟踪表**：风险识别、处置、遗留问题
7. **项目周报/月报**
8. **结项申请单**：正式发起结项
9. **项目总结报告（结项报告）【核心】**
    - 项目概况、目标完成情况、范围对比、进度/成本偏差、成果、问题、经验复盘、后续建议

## 二、需求与设计类（必选）
1. **需求规格说明书 SRS**
2. **需求评审记录**
3. **概要设计说明书（HLDD）**：架构、模块划分、数据流、接口总图
4. **详细设计说明书（LLDD）**：模块内部逻辑、数据库设计、类/函数设计
5. **数据库设计文档 DBDD**：ER图、表结构、字段、索引、字典
6. **接口文档 API Doc**（独立一份，前后端/第三方对接）
7. **UI原型、UI设计稿、交互说明**
8. **设计评审记录**

## 三、开发实现类
1. **源代码**（代码仓库地址、分支Tag、版本说明、打包脚本）✅必归档
2. **代码规范文档**
3. **代码评审记录（CR记录）**
4. **第三方组件/开源软件清单、许可证说明（开源合规清单）**【重要，商用项目必选】
5. **编译构建说明、环境依赖清单**
6. **版本发布说明 Release Note（每个版本）**

## 四、测试类（必选）
1. **测试计划**
2. **测试用例**
3. **测试报告**：测试范围、通过率、缺陷统计、风险结论
4. **缺陷清单（Bug清单）**：已修复、延期遗留、不修复说明
5. **回归测试记录**
6. **性能测试报告 / 安全测试报告**（按需，高并发、对外系统必做）
7. **测试评审记录**

## 五、部署、运维、上线类
1. **部署方案**：环境拓扑、资源清单、网络策略
2. **安装部署手册**（给运维）
3. **运维手册 / 运维规范**：启停、日志、监控、备份、故障排查
4. **用户操作手册（用户手册）**：给最终业务用户
5. **上线方案 & 上线评审单**
6. **上线验证记录**
7. **数据迁移方案、数据迁移校验报告**（涉及存量迁移时）

## 六、验收交付类（甲方/客户侧重点看）
1. **验收方案**：验收标准、验收项、验收方式
2. **验收测试记录**
3. **验收报告 / 验收确认单（甲方签字版）【核心】**
4. **交付物清单**：所有交付文档、程序包、账号、源码、介质清单，双方确认
5. **培训文档 + 培训记录**：给客户运维/使用人员培训
6. **售后维保方案、质保说明**

## 七、其他合规&归档类（可选，看公司/行业要求）
- 安全评估报告、等保相关材料（政务、互联网产品）
- 涉密文档（涉密项目）
- 知识产权材料：软件著作权申请材料
- 合同、补充协议（外包项目）
- 采购清单、硬件清单（软硬件一体项目）
- 介质归档记录（光盘、压缩包MD5校验值）

# ✅ 精简版（小项目、内部自研项目，最少一套）
1. 结项申请单
2. 项目总结报告
3. 需求说明书
4. 概要设计+数据库设计
5. API接口文档
6. 测试报告 + Bug清单
7. 用户手册 / 部署手册
8. 交付清单
9. 源码包+版本说明

交付清单 → 用户手册 → 部署手册 → 接口文档 → 测试报告 → 验收报告 → 结项报告
